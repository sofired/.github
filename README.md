# sofired/.github

Organization-wide files for [Sofired](https://github.com/sofired)
(Southern Fired Software, LLC).

| Path | What it is |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The page GitHub shows on [github.com/sofired](https://github.com/sofired). GitHub reads an organization's profile from this path, not from this file. |
| [`brand/`](brand/) | The Sofired brand: mark, wordmark, avatar, favicons, colour and type. Start with [`brand/README.md`](brand/README.md). |

The files in `brand/` are generated: change `brand/source/build.py` and run
`python3 brand/source/build.py`, rather than editing the SVGs or PNGs by hand.
