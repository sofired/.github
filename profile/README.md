We're Southern Fired Software, and we develop software. The projects below
are tools we built to help with our own development work. We're sharing them
in case they help with yours.

| Project | What it does |
| --- | --- |
| [treerig](https://github.com/sofired/treerig) | A rig for every branch: each Git worktree gets its own Docker Compose stack, data and URL. |
| [composemux](https://github.com/sofired/composemux) | A read-only terminal UI for Docker Compose logs, with live service status and pinned log panes. |
| [tracedoc](https://github.com/sofired/tracedoc) | Validates, renders and compares requirements traceability matrices and threat models kept as JSON, gated in CI. |
| [grizzle](https://github.com/sofired/grizzle) | An early-stage Go port of Drizzle ORM and Drizzle Kit concepts. Not yet released. |

Install our command-line tools with Homebrew from
[sofired/homebrew-tap](https://github.com/sofired/homebrew-tap).
